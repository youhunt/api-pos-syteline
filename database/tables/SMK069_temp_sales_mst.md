## Row meaning

One row is one Customer Order line. Lines are grouped by the same generated `co_num` and original `cust_po`.

Confirmed example:

```text
co_num      = R260822003
cust_po     = POS08270002
co_line     = 1,2
item        = AA00032
unit_price  = 80000
u_m         = CTN
whse        = MAIN
status      = V
```

## Number model V2

```text
cust_po         = original POS order/customer PO
co_num          = final SyteLine CO number generated by Receive
created_co_num  = compatibility/audit copy of co_num after successful Process
```

Example:

```text
cust_po         = POS08270002
co_num          = R260822003
created_co_num  = R260822003 after Process
```

## Primary key

```text
SiteRef + co_num + co_line
```

## Validation before temp

Receive transfers only fully valid `SiteRef + cust_po` orders.

Current validation includes:

```text
required/length checks
customer exists
item exists
whse required and exists
u_m required and equals item base U/M OR item-specific conversion exists
effective customer/item price exists
terms_code exists
duplicate co_line prevention by SiteRef + cust_po
header consistency
atomic order rule
existing cust_po in temp/Blanket CO prevention
```
